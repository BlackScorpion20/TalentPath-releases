# TalentPath – Releases

Fertige Versionen von **TalentPath** für World of Warcraft: Forever (Interface 16001).
Zeigt im Talentfenster, welches Talent als Nächstes dran ist: nach einem Talent-Link von
**Icy Veins** oder **Wowhead**, für alle Klassen.

- Leuchten auf dem nächsten Talent, sobald ein Punkt frei ist; Stufenzahlen auf allen
  Talenten, die der Build noch will.
- Kleines Feld neben dem Talentfenster: die nächsten drei Punkte, Knopf **Nächster Punkt**
  (setzt den Punkt nur vor, übernehmen tust du selbst mit „Änderungen anwenden“).
- Ein Build je Spezialisierung (Primär/Sekundär).

**Link holen:** Icy Veins: im Guide „Open in Calculator“, Adresse kopieren. Wowhead: im
Leveling-Build „In Talentrechner öffnen“, dann Adresse oder „In Zwischenablage kopieren“.
Im Spiel Talentfenster (N) → **Link…** → einfügen → Enter.

**Installieren:** die Zip der neuesten Version unter *Releases* laden und nach
`_forever_/Interface/AddOns` entpacken, oder in der App „WoW Addons“ diesen Link als Quelle eintragen.

Läuft mit **EllesmereUI** (Feld im EUI-Stil) oder der normalen Blizzard-Oberfläche.
